# 表示設定と設定の持ち出し

メインナビゲーションの「設定」にある「表示設定」で、初期表示（すべて／未読／スター付き）と表示タイムゾーン（UTC／日本時間）を保存できます。この2項目はライブラリの共有設定です。初期表示は次回起動に適用し、保存しただけでは現在のフィルターを切り替えません。

日付表示と詳細検索の公開日範囲は、同じタイムゾーンを使います。開始日はその日の午前0時を含み、終了日は翌日の午前0時より前までです。日本時間の1日は、前日の15:00 UTCから当日の15:00 UTCより前までになります。公開日不明の記事は日付範囲検索に含みません。別のブラウザでタイムゾーンを変えた場合は、ウィンドウを再びアクティブにした際に取得します。

別のブラウザによる変更に気づく前に一括操作した場合、操作は中止され、設定を再取得します。日付範囲を確認し、必要なら操作をもう一度行ってください。

記事一覧の「表示形式」から標準・1行・タイルを切り替えられます。追加読込済みのカード、検索条件や記事の選択を保ったまま変更できます。表示形式とテーマ、サイドバー幅、フォルダーの開閉はブラウザごとに保存します。保存領域が利用できない場合も、そのセッションでは操作できます。

「設定をエクスポート」は `feeder-settings.json` をダウンロードします。バージョン情報、収集・表示設定・API回数上限、購読と個別収集間隔、フォルダー／フィードの配列順、現在のブラウザの表示設定を含みます。配列の順序が配置順です。記事本文、既読／スター、履歴、収集エラーや実行記録は含みません。環境変数や認証ファイルは読みません。

URLにユーザー名／パスワード、クエリー、フラグメントがある場合、そのURLを省略します。認証情報を示す文字列がある名前なども省略し、`omissions` に項目の場所と理由だけを記録します。省略した値を別の場所へコピーすることはありません。これは保守的な判定で、任意の名前に秘密を直接書き込む運用を保護するものではありません。

この段階で未移植の機能は `unsupported_sections` へ明記します。設定全体の読み込み・復元にはまだ対応していません。購読の入出力は既存のOPML機能を使えます。データ全体の保全と復旧には、停止したWeb／workerのデータvolumeをバックアップする[配備手順](deployment.md)を使ってください。

旧実装の対応元: `feedastrolabe/preferences.py`、`feedastrolabe/configuration_export.py`、参照仕様 `configuration-export` と `reader-productivity`。任意IANAタイムゾーン、APIリクエスト上限、旧データの完全変換、AI・外部連携設定の書き出しは後続です。
