# 購読 URL 変更の検証

2026-11-06。対象は RSS 購読の URL 修正と収集の競合防止。移行元 `feedastrolabe/subscriptions.py`、`feedastrolabe/api.py`、`docs/api.md` の該当操作に対応する。合成データのみ使用し、実際のフィードや実データへの接続・変更は行っていない。

- Rust の合成テスト45件に成功。本番ルーターのセッション・CSRF／Bearer認証を通し、URLの変更・同一・重複・認証情報付き・ローカルアドレス、権限、途中変更の取消し、記事の既読・スター・履歴保全を確認した。
- 別の SQLite 接続で収集リースを作り、Web／公開 API 双方の編集と削除が409になること、期限切れ後に編集できることを確認した。期限切れの収集結果は保存トランザクション内で拒否し、新しい URL に古い記事やETagを適用しない。
- Linux の専用コンテナで、PCのキーボード操作、重複エラー後の再編集、モバイルでの編集画面、読書・生産性・配置・設定・アクセスの既存ブラウザ回帰を確認。生成データのバックアップ・別volume復元にも成功した。
- GitHub CI、実外部フィード、全テーマと全入力方式の組み合わせ、既存 FeedAstrolabe DB の移行は未検証。SNS・ページ観測と個別収集間隔の移植は別変更で扱う。
