# Article revisions integration contract

Only v10 calls `article_revisions::migrate_catchup(&tx)`. It creates `article_revision_state(article_id, current_revision, fingerprint, first_seen_at, ingestion_kind, changed_at, source_updated_at, history_complete)` and `article_revisions(article_id, revision, fingerprint, title, content, url, published, source_updated_at, observed_at, baseline)`. Rows cascade with their article. Legacy articles acquire a baseline lazily at first collection; before then `current_state` returns None. `ingestion_kind` is `initial`, `normal`, `recovery`, or `legacy`; it records the original observation, never changes on later polls. Thus only `normal` is eligible for a new event. `changed_at` is null for baseline, updated only on a substantive content change. Compare SQLite `julianday(changed_at)` and `julianday(article_visits.visited_at)` for update metadata, requiring an existing visit and a later changed_at. Snapshots retain at most 20 versions; `history_complete` is always false because source history before observation is unknown.

`current_state(db: &Connection, article_id: i64) -> rusqlite::Result<Option<RevisionState>>` exposes `current_revision`, `fingerprint`, and `history_complete`; other state fields are available in the table. `store_entry(tx, feed_id, external_id, title, content, url, published, source_updated_at, kind) -> rusqlite::Result<i64>` replaces each collection UPSERT; kind is `collection_runtime::CollectionContext`. Caller passes `e.updated.map(|d| d.to_rfc3339()).as_deref()` as source_updated_at. The hook updates story index in the same transaction; migrations for both modules must precede collection. The function preserves read/star and existing ancillary state. Fingerprints SHA-256 length-prefixed UTF-8 title/content/URL; publication and source time do not affect the fingerprint. Times supplied as source_updated_at are normalized to UTC by SQLite and invalid times become null.

The history response `history_start` is the earliest retained revision number (null when no snapshot is available). The source timestamp of a legacy baseline is unknown and is stored as null.
