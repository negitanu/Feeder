# ライブラリの配置とサイドバー幅

フォルダー／フィードの左にある「⠿」をドラッグして並べ替えます。フィードをフォルダー行へ重ねると末尾へ移動します。折りたたみ状態は変えません。「フィード（フォルダーなし）」へ重ねるとフォルダーから外せます。

キーボードではハンドルにフォーカスし、上下矢印で1件、Home/Endでグループの先頭／末尾へ移動できます。別フォルダーへの移動はフィードの操作メニュー「フォルダーを移動」から保存できます。ハンドル以外では通常のタッチスクロールを使えます。

順序と所属は共有DBへ保存します。別のブラウザでも同じ並びになります。競合や保存失敗時は最新のライブラリを読み直し、状況を通知します。順序だけの変更では記事一覧の選択・フィルターやフォルダーの開閉は変えません。表示中のフォルダーへの出入りがある場合は、その記事一覧を再取得して記事の選択を解除します。

デスクトップではサイドバーと記事領域の間の境界をドラッグして幅を変更できます。境界へフォーカスして左右矢印で10px、Shift+左右矢印で50px、Home/Endで最小／最大へ調整します。200〜480pxの範囲で、記事領域の幅も確保します。幅はブラウザごとに保存し、スマートフォンでは適用しません。保存領域が利用できなくてもセッション内の操作は続けられます。

現在は空名の旧フォルダーを読み込む変換は未実装です。フォルダーなしはDB上のNULLとして扱い、文字列「未分類」というフォルダーとは区別します。旧DBからの本移行は別段階です。
