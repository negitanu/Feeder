# 実装の優先順位

2026-11-07改訂。目的は高機能な情報収集ツール／RSS・SNSリーダー。調査・研究機能の移植と、そのための依存関係を計画から削除する。

現在の実装状況・優先順位・改善アイデアは [残タスク一覧](remaining-port-tasks.md) に集約する。

- P0: 読書の信頼性、Feederデータの保全、認証・依存・運用の受入。
- P1: 読書UI、SNS収集、購読と収集状況の管理。
- P2: Reader向けAPI互換性、設定の持ち運びと選定した改善アイデア。

SNS収集は研究・根拠基盤に依存させない。OpenSpecで要件・受入を定義し、合成データと模擬接続で機能単位に進める。実外部サービスの受入は別途記録する。

公開時にはAccess認証、整合バックアップと復元、PC／モバイル・テーマ・入力方法、秘密と依存の確認を行う。未確認を成功扱いしない。旧データ移行・デスクトップ・同期は対象外。
