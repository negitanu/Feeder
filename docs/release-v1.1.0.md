# Feeder v1.1.0

Feeder v1.1.0は、情報収集の信頼性、読書一覧、設定の持ち運びを改善するリリースです。

- RSS取得時のアプリ識別と大きなフィードへの対応を改善し、収集失敗の原因と再試行予定を表示
- 公開Mastodon／Blueskyの継続取得を改善し、公開APIからのSNS購読と種別ごとの記事絞り込みに対応
- 関心語ごとの記事数の変化と新しい配信元を表示
- 重複記事をライブラリ全体から探し、古い範囲や同じURLの多数の記事を順に表示
- 設定JSONのプレビュー付き読み込み、ブラウザ表示の任意復元、選択記事のリンク書き出しを追加
- PC／モバイルの記事一覧を区切り線で整理し、モバイルでは日付を短く表示
- バックアップ検証と復元手順、中断されたSQLiteトランザクションの安全な復旧を追加
- SQLiteを含むRust依存関係を更新

## 更新前に

[配備・バックアップ・復元手順](deployment.md)に従い、Webとworkerを停止してデータ全体の整合バックアップを作成してください。設定JSONやOPMLは記事・既読状態を含む完全バックアップではありません。

RSS取得、キャッチアップ、SNS収集には処理上の上限があります。SNSサービスの取得完全性や長期的な可用性は保証されません。設定JSONでは購読と配置順は復元されず、購読の持ち運びにはOPMLを利用できます。詳細は[残タスク](remaining-port-tasks.md)を参照してください。
