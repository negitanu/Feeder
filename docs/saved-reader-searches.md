# 保存した検索

記事一覧の「保存した検索」から、適用済みの検索語・表示区分・情報源・詳細条件に名前を付けられる。保存はブラウザー単位で最大50件。未適用のフォーム入力、選択記事、追加読込カーソルは保存しない。

保存済みの名前を押すと条件を呼び戻す。情報源が削除されている場合は変更せず理由を表示する。日付条件は現在の表示タイムゾーンを使う。不要な検索は削除できる。保存領域が使えない場合は現在の画面内だけの利用となり、案内を表示する。

この機能はブラウザーをまたぐ共有やDBへの保存、設定エクスポートにはまだ対応していない。秘密を含む検索語はブラウザーの保存領域にも残るため、検索名や検索語の入力時に考慮する。
