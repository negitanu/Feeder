# 購読と収集状態、記事の読みやすさ

設定の「購読・収集」では、購読管理と収集状態を同じ一覧で確認できます。タイトル・URL・フォルダーで検索し、稼働中・停止中・エラー・古い状態で絞り込めます。各行の詳細で収集時刻や診断を確認し、編集、停止・再開、更新ができます。停止中または再試行待ちのフィードは更新できません。

一括停止・再開は最大100件です。検索や絞り込みで隠れた選択も対象になるため、実行前に選択数を確認してください。収集状態の取得に失敗した場合や上限に達した場合、未取得の状態は不明と表示し、取得済みの購読操作は引き続き利用できます。

「表示・読書とデータ」の「記事の読みやすさ」では、記事本文の文字サイズ・行間・最大幅を調整できます。変更は直ちに適用され、このブラウザーに保存されます。保存できない環境では現在のページに限って適用されます。実際の幅は画面や記事ペインの利用可能な幅を超えません。
