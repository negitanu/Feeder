# 詳細右端と中クリック既読

2026-11-07。詳細の位置を画面中央の1500pxコンテナ基準から変更し、全画面幅でright:0とする。モバイルも右端を揃え、左側と下側の余白は保つ。

安全な元記事URLを中クリックすると別タブを同期的に開き、既存のstate APIで既読にする。成功後にカード・未読件数・未読一覧を反映。処理中の同一記事への重複更新を抑止し、詳細visitと未読除外の記録を共有して二重減算を防ぐ。通信失敗時はエラーを表示して再試行できる。スターや詳細閲覧履歴は変更しない。不正なURLではタブも更新も発生しない。

生成記事を用い、初期／追加読込のカード、中クリック連続操作、未読一覧からの除外、未読件数、失敗と再試行、1920px／390pxの右端位置を検証した。旧「中クリックでは既読にしない」仕様はこの変更で置き換える。

型検査・ビルド、読書・詳細レイアウト・中クリックのブラウザー回帰と別volumeへのバックアップ復旧が通過。OpenSpec全53項目を検証した。
