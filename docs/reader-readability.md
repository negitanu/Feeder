# 記事の読みやすさ

記事詳細の読みやすさは、ブラウザごとに設定できます。文字サイズは 13〜22 px、行間は 1.5〜2.4 倍、本文の最大幅は 40〜90 ch です。変更はすぐに記事本文へ反映され、「初期値に戻す」で文字サイズ 16 px、行間 1.9 倍、最大幅 70 ch に戻せます。

設定は `feeder-readability` キーでブラウザの `localStorage` に保存し、共有ライブラリ設定や記事データには書き込みません。保存済みの値は範囲内に補正し、壊れたデータは初期値に置き換えます。ブラウザが保存を拒否した場合もページ内の変更は有効で、パネルが保存できないことを案内します。

親アプリは起動時、記事を描画する前に `ReadabilityPanel.tsx` の名前付き `applyReadability()` を呼び出します。設定パネルは同モジュールの props 不要のデフォルトコンポーネントです。ルート要素に `--readability-font-size`、`--readability-line-height`、`--readability-max-width` を適用し、`readability.css` は `.article-text` の文字組みと `.article-body` の上限幅だけを調整します。

## 既存 Web 仕様・実装との対応

- `openspec/specs/reader-foundation/spec.md` の Web 記事詳細に対する任意のブラウザ表示設定です。サーバーAPIや共有設定仕様は変更しません。
- 既存 `frontend/src/style.css` は `.article-text` に 14 px・行間 2.1 を指定し、`.article-detail` は最大 740 px です。本機能はカスケードで本文の文字サイズ・行間を上書きし、`.article-body` を親幅以下かつ設定された ch 幅に制限します。
- `frontend/src/ReaderSettingsPanel.tsx` のブラウザ内プレゼンテーション設定と同じく、サーバー保存の設定とは分離します。

## 受け入れ条件

- 起動適用時に保存値を安全に読み込み、破損値・未知の型・localStorage拒否でも安全な初期値をCSS変数に設定する。
- 3つのラベル付き範囲入力が即時反映され、読み上げ可能な現在値と保存状態を提供する。
- 保存拒否時も操作を継続でき、保存できないことをステータスで伝える。
- リセットは全項目とCSS変数を初期値へ戻す。
- 本文が狭い画面や詳細枠に収まるようにし、スタイルの適用対象を記事本文に限定する。
