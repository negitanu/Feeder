# 記事詳細の前後移動の検証

2026-11-07。旧Web版の詳細末尾にある前後移動と位置表示を、Feederの読み込み済み一覧に対応させた。検証には生成データを使用した。

- 詳細を開いた時点の順序を保持し、先頭・末尾で対応するボタンを無効化する。追加ページの自動取得は行わない。
- Linuxコンテナとブラウザで、キーボード操作、移動失敗後の再試行とフォーカス、一覧・選択の保持を確認。未読一覧からの移動と再訪でも未読件数が二重に減らないことを確認した。
- 読書・設定・サイドバー・アクセス制御の画面回帰と、非root・read-only・データ永続化・別ボリュームへのバックアップ復旧を確認した。
- 後続の `reader-detail-arrow-keys` で、詳細内の左右キーによる前後移動、範囲外、入力欄、修飾・長押し・変換中、詳細外のキーを合成データで確認した。詳細内でフォーカスを持つ場合に限り動作する。
- URL・ブラウザ履歴、未読込ページへの移動は対象外。全ブラウザ・全テーマの網羅は行っていない。
