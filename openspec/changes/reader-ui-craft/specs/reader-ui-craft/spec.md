## ADDED Requirements
### Requirement: Consistent reading interface
Existing reader, sidebar, detail, settings and dialogs SHALL use consistent spacing, controls, iconography and legible metadata while retaining functions and section order.
#### Scenario: Browse and configure
- **WHEN** a user reads or changes settings on desktop or mobile in light, dark or system appearance
- **THEN** controls remain legible, keyboard focus is visible and content stays within the viewport.
### Requirement: Preserve reading preferences
The visual polish SHALL respect stored readability settings and reduced-motion preferences.
#### Scenario: Read with preferences
- **WHEN** saved typography settings are applied
- **THEN** they continue controlling article text after the polish stylesheet is loaded.
