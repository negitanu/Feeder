## Design

Expose an authenticated same-origin GET /api/articles/{id}/hero. Detail and visit supply image_url as that relative URL when an original URL exists, otherwise null. The URL is a candidate, not a guarantee of an image. On demand, fetch only the stored original URL with the existing public-address, credential-free HTTP(S), DNS pinning, redirect, size and timeout protections; parse og:image or twitter:image and resolve relative to the final page URL. Fetch the selected image through the same protections and serve only verified raster formats, never SVG. Bound simultaneous work and cache successes and failures for a short time with bounded memory. Never accept a caller-supplied URL. No database or backup changes are needed. Existing access middleware protects the route; image requests do not mark articles read or record visits.
