## 要件: 明示した関心語の動向

利用者はキャッチアップの期間と対象について、共有設定の各関心語に一致する保存記事の実件数、前の同じ長さの期間との増減、新しい配信元を確認できる。期間・対象・判定方法・集計上限および収集状態を表示する。

### シナリオ: 同じ期間との比較
- **WHEN** 過去24時間を選ぶ
- **THEN** 現在の24時間とその直前24時間を重複なく比較する
- **AND** 既読や確認済みも数え、ミュート記事は含めない

### シナリオ: 集計が不完全
- **WHEN** 評価上限に達するか収集が不完全である
- **THEN** 対応する注意を表示する
