## ADDED Requirements
### Requirement: 非破壊のミュート
有効なルールは指定配信元または全配信元の記事のタイトル、本文、URL、またはタイトルと本文にリテラル部分一致する。最大100件、term は空白のみ不可、200 UTF-16 単位以内。正規表現や SQL ワイルドカードとして解釈しない。
#### Scenario: 一致した記事
- **WHEN** 有効なルールに記事が一致する
- **THEN** 通常の一覧および同じ条件の一括操作から除外し、記事、既読、スターその他の状態を変更しない
#### Scenario: 停止または対象外
- **WHEN** ルールが無効または配信元が異なる
- **THEN** そのルールは記事を隠さない
#### Scenario: 理由と復帰
- **WHEN** ミュート理由を問い合わせるか明示的にミュートを含める
- **THEN** 一致した有効ルールの ID と名前を取得でき、記事を再表示できる
### Requirement: 設定と競合
CRUD と有効切替は入力検証と revision による競合検知を行う。
#### Scenario: 古い編集
- **WHEN** 古い revision で変更または削除する
- **THEN** 409 を返して新しい設定を保持する
