## ADDED Requirements
### Requirement: 収集失敗の説明
収集状態は安全な分類を用いて失敗原因と適切な復旧の次の行動を表示しなければならない。
#### Scenario: 配信元がHTTPエラーを返した
- **WHEN** 配信元が失敗ステータスを返す
- **THEN** ステータスと復旧案を表示し、応答本文や秘密を記録しない。
#### Scenario: 待機中の失敗
- **WHEN** 再試行期限が未来である
- **THEN** 再試行ボタンは無効となり、期限を表示する。
#### Scenario: 旧形式のエラー
- **WHEN** 詳細が記録されていない過去の失敗を表示する
- **THEN** 原因を推測せず、詳細が不明である旨を表示する。
