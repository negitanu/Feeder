# 設計
配信元HTTPステータス、DNS、接続、タイムアウト、本文取得、リダイレクト、安全制限、サイズ超過、フィード解析を固定の安全な診断コードとして記録する。URLや応答本文、秘密を記録しない。既存の feeds.last_error の文字列に診断コードを付加し旧形式との互換を維持する。SNSとRSSの共通HTTP経路で診断し、失敗完了は引き続き有効なリース所有者のみが記録する。期限前の手動再試行は禁止しRetry-Afterを遵守する。画面は診断別の説明と次の行動、最終成功と次回予定を示し、購読管理へのリンクを提供する。旧診断は不明として表示する。

受入: 模擬の各失敗原因と古い書式、リース切れ、待機、429/503の保持、診断APIと画面の動作を確認する。
