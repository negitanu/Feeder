## Design
Main owns schema/version/auth and reader SQL. Agents own disjoint feature modules exposing migrate(tx) and routes(). A v9 candidate schema is reconstructed in memory and compared exactly before writes. Prior known databases are backed up before additive tables. Read-later state is independent from star and changes only through explicit save/remove or optional visit preference. Mute filtering is shared by listing and scoped bulk operations; viewing hidden items is explicit. Browser row layout uses feed title, article title and absolute timestamp. Security/limits and feature APIs are specified in individual changes.
