# Design

Below 768px, standard and line layouts use source and date above a two-line title. A Select button enters bulk mode. Left swipe toggles read state; right swipe reveals explicit save and star buttons so either action can be chosen without relying on color. Gestures begin away from the system edge, respect vertical scrolling, and coexist with pull to refresh and the library drawer. Article detail is a full-screen independently scrolling surface with accessible fixed bottom actions and safe-area padding. Library ordering is opt-in on mobile; desktop handles remain unchanged.
