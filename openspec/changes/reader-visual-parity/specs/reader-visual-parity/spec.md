## ADDED Requirements
### Requirement: Source-aligned accessible shell
The React shell SHALL use FeedAstrolabe's light/dark palette, shared eight-ray brand mark, compact reader cards and visible navigation state.
#### Scenario: Reading in different appearances
- **WHEN** a user reads on desktop or mobile in light, dark or system mode
- **THEN** controls and article content remain readable and the selected navigation is visible.
### Requirement: Keyboard and motion access
The shell SHALL expose a skip-to-main link and respect reduced-motion preferences.
#### Scenario: Skip navigation
- **WHEN** the user activates the skip link
- **THEN** focus moves to the main content.
