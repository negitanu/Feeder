# 画面の方向と確認点

- 製品: RSS・SNSの購読記事を日々読むためのReader
- 印象: 落ち着いた、明瞭な、親しみやすい
- 世界観: 紙面とインク、静かな閲覧環境
- 見せ場: 情報源と記事タイトル、重要な記事の画像
- 印: 既存のFeederマークと未読を示す小さな点

## 変更前の確認

- モバイルの1行表示: 発行元・時刻とタイトルが別行になり、タイトルも折り返していた
- モバイルのタイル表示: 1列へ固定され、標準表示との違いが小さかった
- 色: 画面全体が青緑に寄り、本文と補助情報の区別が弱かった
- ナビゲーションと情報量: 既存の構成と操作を保ちながら、記事の表示密度を選択できるようにする

配色は無彩色寄りの背景と青灰色のアクセントに整理する。実際の記事内容を視覚的な中心に置き、装飾画像は追加しない。Unslop by Damir Sokolovsky (@heydamir), CC BY 4.0.
