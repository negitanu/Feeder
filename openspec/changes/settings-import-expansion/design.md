# 設計と受入
1 MiB以下のFeeder v1 JSONをブラウザーで確認する。サーバーは表示、収集、API上限と既存フォルダー名の現在値を返す。プレビューは現在値と新値、追加・既存・省略のフォルダーを明示。適用時には現在値とフォルダー集合の一致を同一即時トランザクションで確認し、競合時は409で何も変更しない。妥当な名前のみ追加し、同名は再利用し、既存の順序・購読・記事を変更しない。フォルダーはファイル内順に末尾追加。秘密を疑う名前は拒否し、nullは省略として扱う。購読は対象外としてOPMLを案内、ブラウザー表示設定、APIキー、秘密、未対応セクションも読み込まない。1,000件のフォルダー上限、整数・列挙検証、同一オリジンとCSRF境界を維持する。
