# Design

Default to a 52/48 split of the space remaining after the library. A keyboard- and pointer-operable separator stores the preferred ratio locally, with minimum usable pane widths and resize clamping. A container query switches non-tile list rows to two-line titles when the list is narrow, without changing the stored layout. The detail pane uses a single sticky action bar, centered configurable reading column, source metadata, estimated reading time and constrained hero image. Original links are validated as HTTP(S).
